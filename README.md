# ITI ID Card Generator — Updated

Files:
- index.html
- style.css
- script.js

Features:
- Excel upload
- Enrollment No. detection
- Search by name/enrollment/roll
- Trade filter
- Multiple student selection
- Student photo upload
- Photo matching by enrollment/roll/name in filename
- Individual print
- Bulk print
- Selected PDF
- All filtered PDF
- A4 two-card print layout

## GitHub replacement
In your repository:
1. Open `index.html` → Edit → Select all → replace with the new index.html → Commit.
2. Open `style.css` → Edit → replace all → Commit.
3. Open `script.js` → Edit → replace all → Commit.
4. Wait 1–5 minutes and refresh GitHub Pages.

## Photo naming
Best results: name each photo with the enrollment number, roll number, or exact student name.
Example:
123456789.jpg
12.jpg
Ramesh Patel.jpg

The browser does not upload the Excel/photos to a server.
